# Changelog

## 1.6.0 (2026-11-08)

Token savings across the pack. Every skill gets a *Token budget* section (lite output first, read only what is needed, small models for mechanical steps, small swarms first, no recurring run without approval, short threads, small edits). Long skills trimmed: detail moved to `reference.md` in `founder-supply`, `founder-legal`, `founder-research` and `founder-human-development`. `founder-chief-of-staff` becomes the token steward (Mode 7 efficiency check, *Consumo* line in the weekly brief, `usage.md`, *Waste* in connect-the-dots). `founder-skill-audit` adds criterion 10, token efficiency (now out of 30). `founder-learning` and `founder-research` share one run every two weeks. README and getting-started prompt updated. Includes 1.4.0 and 1.5.0.
